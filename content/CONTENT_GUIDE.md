# Content guide — adding a unit

Read CLAUDE.md §4 first, especially **"Rules for producing content and data"**:
write all sentences and dialogues yourself, never type out existing lists or texts,
and add **one unit per file per response**.

## Files
- `course.json` — section order, plus "upcoming" placeholders. Add the new unit id to a section, and remove its placeholder.
- `units/NN-name.json` — one unit: `words`, `sentences`, `exchanges`, `grammar`, `dialogue`, `nodes`.
- `sounds.json` — single syllables for tone and minimal-pair drills.
- `hsk/hsk-levels.json` — generated by `npm run hsk:fetch`. Never edit by hand. Use it to look up a word's HSK level.
- `REVIEW_NEEDED.md` — anything you're unsure about.

## IDs
Lowercase with dashes, globally unique across all files. Use a `w-` prefix for words (`w-chi`), `s-` for sentences (`s-wochibaole`), `x-` for exchanges, `g-` for grammar, `n<unit>-` for nodes and `d<unit>-` for dialogues. Many words share a pinyin spelling (会/回, 进/斤, 碗/玩), so search the existing units before choosing an id, and give the newer word a meaning hint: `w-ta-she`, `w-zai-again`, `w-hui-return`, `w-wan-play`. The validator reports any clash.

## Words
`{ id, hanzi, pinyin, english[], hsk, pos, note?, measure?, examples? }`
- `pinyin` uses tone marks, with syllables of one word joined (`péngyou`). Neutral tone has no mark.
- `hsk`: look the word up in `hsk/hsk-levels.json`. If it isn't in HSK 1–3 there, use `0`. The validator warns on mismatches.
- `measure`: the id of its usual measure word (for the Measure Word game).

## Sentences
`{ id, hanzi, pinyin, english, words[], alt? }`
- `words` are word ids **in order**, and their characters must spell the sentence exactly (punctuation aside). Every word must be defined in this unit or an earlier one.
- Write pinyin the way it's spoken for 不/一 (`bú shì`, `yí ge`). Leave 3rd-tone sandhi unmarked (`nǐ hǎo`).
- Avoid erhua (儿) for now: use 哪里 rather than 哪儿, and 一点 rather than 一点儿.
- Use natural everyday Mainland Mandarin, simplified characters. Prefer contexts from life with a partner's family.
- Dialogue lines that combine two short sentences need their own combined sentence entry.
- `alt.english` / `alt.pinyin` list other acceptable answers.

## Exchanges ("What would you say?")
`{ id, prompt, reply, wrong[≥2], context }` — sentence ids. `wrong` replies must be clearly wrong in that context, not just less polite.

## Grammar notes
A short English explanation (one idea), plus example sentence ids. Shown as the Tips card on the nodes that list them.

## Dialogue (one per unit, ending the unit)
`speakers` (each with `voice: "f" | "m"`), `lines` (speaker + sentence id), and 3–4 English multiple-choice `questions` with an `answer` index. Original story, 6–10 lines, reusing the unit's sentences.

## Nodes
3–5 lesson nodes of 4–9 new words each, then one `"kind": "story"` node. Each lesson node lists its new `words`, practice `sentences`, `exchanges` and `grammar`. Lessons are generated automatically from these.

## Check your work
```bash
npm run content:validate -- --allow-missing-audio   # audio is generated by CI
npm test
```
Then commit and push. CI generates the audio, and the next deploy includes it.
